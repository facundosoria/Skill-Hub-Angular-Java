# NNNN. Título corto en forma de decisión

- **Estado:** Propuesto | Aceptado | Reemplazado por [NNNN](NNNN-titulo.md) | Obsoleto
- **Fecha:** AAAA-MM-DD (fecha en que se tomó o registró la decisión)

## Contexto

Qué problema o fuerza obligó a decidir. Restricciones técnicas, del equipo o
del entorno que existían en ese momento. Hechos, no opiniones.

## Decisión

Qué se decidió, en voz activa ("Usamos X para Y"). Incluir los detalles que un
lector necesita para reconocer la decisión en el código (rutas, clases,
migraciones, configuración).

## Alternativas consideradas

- **Alternativa A:** por qué no se eligió.
- **Alternativa B:** por qué no se eligió.

Si no hay registro de qué se evaluó, escribir: *Razón no registrada — confirmar.*

## Consecuencias

- Positivas: qué se gana.
- Negativas / costos: qué se pierde o qué queda como deuda.
- Riesgos y límites conocidos.

## Referencias

- Commits (`git show <hash>`), migraciones, archivos de código y documentos
  relacionados. Rutas relativas a este archivo.
